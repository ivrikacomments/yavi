# Папка для живого просмотра

Открывайте `index.html` через HTTP или загрузите содержимое этой папки в корень статического хостинга.

- `index.html` — текущий визуальный макет.
- `style.css` — стили.
- `assets/` — WebP-копии изображений.
- `fonts/` — локальные шрифты и их лицензии.

GitHub Pages публикует эту папку по адресу https://ivrikacomments.github.io/yavi/.

Источник находится в `design-preview/`. Для обновления выполните из корня проекта `python scripts/build-live.py`.
