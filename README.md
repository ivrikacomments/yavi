# Виктория Ярмолинская

Репозиторий содержит новый визуальный макет сайта коуча, его изображения, шрифты и папку для живого просмотра.

## Живой просмотр макета

- Публичный просмотр: https://ivrikacomments.github.io/yavi/
- **`live/`** — самостоятельная папка для публикации. Её содержимое можно загрузить в корень статического хостинга.
- GitHub Pages публикует только `live/`. Workflow: `.github/workflows/pages.yml`.
- Источник текущего дизайна: `design-preview/soft-direction.html` и `design-preview/soft-direction.css`.
- Декомпозиция: `design-preview/decomposition.md`.

Это визуальный макет для согласования. Формы, переходы и подключение CMS выполняются на этапе сайта после согласования дизайна.

### Локальный просмотр

Из корня проекта:

```powershell
python -m http.server 8734 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8734/live/.

### Обновление папки live

После правок исходного макета выполните:

```powershell
python -m pip install Pillow
python scripts/build-live.py
```

Скрипт копирует текущий HTML/CSS и шрифты, создаёт WebP-копии изображений и исправляет пути. Файлы в `live/` готовы к публикации без Node или PHP. Закоммитьте исходники и обновлённую `live/`; после push в `main` GitHub Actions обновит просмотр.

## Материалы дизайна

- `docs/homepage/` — описание сайта, дизайн и сведения об изображениях.
- `homepage-design-assets/` — исходные изображения и локальные шрифты.
- `design-preview/assets/` — книга и фон мини-курса, а также сохранённые промпты.

Функциональный сайт с CMS разрабатывается после согласования визуала. Действующий лендинг хранится отдельно.

В Git не включаются локальные настройки с доступами, зависимости Node, сборки и скриншоты проверок.
